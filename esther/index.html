Design with rules. Code with care.

Frontend developer from Taiwan 🇹🇼, based in Vancouver. I've been building accessible interfaces since my teens, because the web should work for everyone.

My roots are in CSS 🎨 and UI work. I tend to think about layout, structure, and interaction details before worrying about clever abstractions. If something looks fine but feels wrong to use, I will notice 👀.

//

At 16, a classmate once built a website in fluorescent green on black and showed it off in class. I told him it was hard to read. He said: “At least I can build one. Can you?”

Reader, I learned. 😤
That fluorescent green never left me.

I started teaching myself HTML and CSS out of spite, mostly. It never felt like "programming". It felt like design with rules. Still does.

In 2022, I moved to Vancouver to formally study User Experience Design, which gave language and structure to things I'd been intuitively doing for years. These days, I work at the intersection of design and development, focusing on clean front-end code 🧩, predictable keyboard interactions ⌨️, and accessibility that holds up in real products.

I've worked on projects for museums 🏛️, libraries 📚, NGOs 🌱, and public institutions across Canada. I like collaborative environments, thoughtful constraints, and the quiet satisfaction of interfaces that don't get in the user's way.
